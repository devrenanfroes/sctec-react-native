# Código Técnico — exercícios por semana

Repositório de exercícios de JavaScript, HTML e CSS organizados por semana.

## Regras críticas

- Preserve o objetivo didático e o escopo da semana; não introduza framework ou dependência sem
  pedido explícito.
- Cada subdiretório pode ter comandos próprios. Leia o README da semana somente quando a tarefa a
  envolver.

## Descoberta e validação

Use `rg` e leitura direta para localizar exercícios. Para JavaScript, execute somente o exercício
afetado com `node`; para HTML/CSS, valide o arquivo ou página afetada. Documentação durável fica
no README da semana ou na raiz quando alterar a organização do curso.
