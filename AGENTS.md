# AGENTS.md — sctec-react-native (curso SENAI/SCtec)

Exercícios do curso de Desenvolvimento Mobile com React Native (SENAI / SCtec).
**Não é projeto de produção: é material de estudo do Renan.**

Regras gerais da pasta de projetos: [`../docs/agent-workflow.md`](../docs/agent-workflow.md).

## Regras específicas

- **Não resolva o exercício por ele por padrão.** O objetivo é aprender: explique o conceito,
  aponte o erro, mostre o caminho. Só escreva a solução completa se ele pedir a solução.
- Mantenha o código no nível do que já foi ensinado (a pasta segue a ordem das semanas).
  Nada de padrão avançado, abstração ou biblioteca que não faz parte da aula.
- Não refatore exercícios antigos nem "organize" as pastas por conta própria — a bagunça
  cronológica é o histórico das aulas.
- Comentários e explicações em português.
