Funcionalidade 1 – Registrar vagas disponíveis
No início do expediente, o estacionamento possui 20 vagas numeradas de 1 até 20.
O sistema deve exibir:

Vaga 1 disponível.
Vaga 2 disponível.
...
Vaga 20 disponível.

Funcionalidade 2 – Entrada de veículos
Durante o dia, os veículos continuam entrando no estacionamento.

A cada veículo estacionado, a quantidade de vagas diminui em 1.
Quando todas as vagas forem ocupadas, o sistema deve informar:

Estacionamento lotado.
Funcionalidade 3 – Menu do sistema
Sempre que o operador abrir o sistema, o menu deve aparecer pelo menos uma vez.
Após executar uma operação, o sistema pergunta:

Deseja realizar outra operação? (S/N)

Enquanto a resposta for S, o menu deverá aparecer novamente.
Quando a resposta for N, o sistema será encerrado.
